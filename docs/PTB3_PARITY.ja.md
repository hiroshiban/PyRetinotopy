# PTB3との開始位置・走査順の対応 - v0.3.0

原版のMATLABファイルは変更していません。`Presentation` と `Generation` の計算式を読み、独立した参照式とPython版の全70モードを照合しました。MATLABを実行した画像の画素比較ではありません。

## 既定値の開始位置

| 刺激 | 原版に合わせた動作 |
|---|---|
| cw | 中心90度（真上）から時計回り。設定開始角-114度、幅48度 |
| ccw | 中心102度から反時計回り。30画像をN..1の順に呈示するため、真上から12度進んだ位置が先頭 |
| exp | 中心側から外側へ25位置。2秒刻み、活動50秒・休止10秒 |
| cont | 10秒休止の後、半径8度側から中心側へ25位置 |
| 複合4種 | 上記の極角開始位置。環は16位置・2秒刻み・公称幅1度。拡大は活動32秒の後8秒休止、縮小は8秒休止の後に活動32秒 |
| bar | 最初の法線角0度では右端（中心x=8度）から左へ。全9走査方向・各16位置を照合 |
| multifocal | 領域0は右水平から画像の時計回り方向。既定は12極角×3離心度の一意な領域ID |
| meridian | 水平子午線の対向楔形から始まり、垂直子午線と交互 |
| lgn | 左側の幅140度から始まり、水平反転した右側と交互。カスタム開始角でも180度回転に置換しない |
| hrf | 全周刺激から始まり休止へ |
| localizer | 半径2.7〜3.8度の帯から始まり、休止を挟んで補領域へ |

時計回り・縮小の休止を走査前へ置く原版の規則も維持します。ccw / cwの既定の極角休止は0秒です。各刺激の前後には既定で4秒ずつの注視があります。

## 座標の扱い

`stimulus.spatial_convention: "ptb3"` が新しい既定値です。設定の `start_angle_deg` と `dual_ring_start_angle_deg` はPTB3と同じ画像座標（右0度、下方向へ正）です。`checker_phase_deg` 等も原版の角位相へ適用します。内部成分・出力窓は視野座標（右0度、上方向へ正）で、画像上端の行が視野上方です。

PTB3の楔形画像indexをj（0始まり）とすると、視野座標での先頭辺は `-start_angle_deg - j*step_angle_deg - wedge_width_deg` です。cwはj=0から、ccwはj=N-1から始めます。単に正負を反転するだけではccwの1ステップ差が残ります。

複合環の位置数は `(360 / step_angle_deg) * (eccentricity_cycle_s - eccentricity_rest_s) / (polar_cycle_s - polar_rest_s)` です。環独自の周期を使って24位置とする旧Python式を修正しました。原版で位置数が整数になる条件を使い、整数にならない条件はエラーにします。楔形と環の重なりでは原版と同じく楔形のチェッカーを優先します。

## multifocalの明示的な違い

原版 `mf_GenerateCheckerBoard1D.m` はゼロ位相時に `true_nwedges=ndivsE` とし、12極角×3離心度では異なる領域のIDが重複します。既定の `multifocal_indexing: "corrected"` は `sector + ring*sectors` を使い36領域を一意にします。これは既存Python版の修正方針を維持したものです。

歴史的な原版のID重複を再現する場合は `multifocal_indexing: "ptb3"` とします。phase 0・幅360度のときだけ利用でき、`sector + ring*rings` を使います。この設定も取得設定に保存します。既定のcorrected窓を過去のMATLAB窓と同一とは扱わないでください。

## 旧Python版の結果の再現

v0.2.2以前の開始位置を再現する場合は `spatial_convention: "legacy-python"` を指定します。旧取得の `config.json` に当該項目がなく、同じフォルダの `summary.json` がバージョン0.2.2以前を記録していれば自動認識します。明示設定があればそちらを優先します。通常の設定JSONや被験者設定は新しい既定値を使います。バージョン情報がない旧ファイルでは明示的にlegacy-pythonを設定してください。

開始位相が変わるので、旧版と新版の結果を区別し、解析窓は各取得に保存されたconfig.jsonから再生成してください。取得済み結果は書き換えていません。

## 検証と限界

連続座標の刺激窓と原版の参照式を照合する自動テストは、`python -m unittest discover -s tests -v` で実行できます。参照式は `tests/reference_ptb3.py` に含まれます。開始角・幅・ステップの変更、休止前後、LGNの非対称角、multifocalの原版ID互換もテストの対象です。

これは連続座標の刺激窓の検証です。原版はPPDの整数丸め、1.01倍のラスタ余白、ceil境界等を使うため、画素境界や中心注視点の差は残り得ます。チェッカー色列・課題列・乱数キャリアのフレームバッファ同一性や、装置での光学的同一性は主張しません。ラン長・周期・ブロックの累積目標時刻と絶対時刻制御は変更していません。
