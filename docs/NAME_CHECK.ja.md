# PyRetinotopyの名称確認

2026-11-06（日本時間）に、次の公開APIを確認しました。

- [GitHub repository search API](https://api.github.com/search/repositories?q=PyRetinotopy+in%3Aname)：HTTP 200、`total_count: 0`、`incomplete_results: false`。
- [PyPI project JSON API](https://pypi.org/pypi/pyretinotopy/json)：HTTP 404、`Not Found`。

この時点の調査範囲では、同名の公開GitHubリポジトリやPyPI登録は見つかりませんでした。正式表示名は **PyRetinotopy**、Python import・配布・コマンド名は **pyretinotopy**、起動スクリプトは **PyRetinotopy.py** とします。

原版Retinotopyへの出典と謝辞は保持します。過去の取得ログに保存された名称・時刻・絶対パスは、当時の記録として保持しています。画像バンクと既成動画の形式名は新名称へ移行し、画素データを変更せずに再利用しています。
